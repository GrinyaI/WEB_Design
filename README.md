# Видеотека

Веб-приложение для управления коллекцией фильмов с административной панелью.

## О проекте

Видеотека - это современное веб-приложение для любителей кино, которое позволяет:
- Просматривать коллекцию фильмов
- Искать фильмы по названию
- Фильтровать фильмы по жанрам и режиссерам
- Управлять контентом через административную панель

## Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP 7+
- **Database**: MySQL
- **Icons**: Font Awesome 6

## Установка и настройка

### 1. Требования

- Веб-сервер (Apache/Nginx) с поддержкой PHP
- MySQL 5.7+
- PHP 7.0+ с расширениями:
  - mysqli
  - json

### 2. Настройка базы данных

1. Создайте базу данных MySQL:
```sql
CREATE DATABASE videoteka CHARACTER SET utf8 COLLATE utf8_general_ci;
```

2. Создайте пользователя:
```sql
CREATE USER 'videouser'@'localhost' IDENTIFIED BY 'password123';
GRANT ALL PRIVILEGES ON videoteka.* TO 'videouser'@'localhost';
FLUSH PRIVILEGES;
```

3. Запустите скрипт создания таблиц:
```
http://ваш-сайт/api/create_database.php
```

### 3. Настройка подключения

Отредактируйте параметры подключения в файлах API (api/*.php):
```php
$servername = "localhost";
$username = "videouser";
$password = "password123";
$dbname = "videoteka";
```

### 4. Загрузка на сервер

1. Загрузите все файлы проекта на веб-сервер
2. Убедитесь, что папка `api/` доступна для выполнения PHP
3. Проверьте подключение к БД:
```
http://ваш-сайт/api/check_connection_to_bd.php
```

## Использование

### Публичная часть

- **Главная страница**: Просмотр популярных и новых фильмов
- **Фильмы**: Полный каталог с возможностью фильтрации
- **Жанры**: Просмотр фильмов по жанрам
- **Режиссеры**: Просмотр фильмов по режиссерам
- **Поиск**: Быстрый поиск по названию фильма

### Административная панель

Доступна по адресу: `admin.html`

Функции:
- Управление фильмами (добавление, редактирование, удаление)
- Управление режиссерами
- Управление жанрами
- Авторизация через OAuth

## API Эндпоинты

### Публичные
- `GET /api/films.php` - Список всех фильмов
- `GET /api/genres.php` - Список жанров
- `GET /api/directors.php` - Список режиссеров
- `GET /api/search.php?q=запрос` - Поиск фильмов
- `GET /api/films_by_genre.php?genre_id=id` - Фильмы по жанру
- `GET /api/films_by_director.php?director_id=id` - Фильмы по режиссеру

### Административные
- `POST /api/admin_films.php` - Управление фильмами
- `POST /api/admin_directors.php` - Управление режиссерами
- `POST /api/admin_login.php` - Авторизация

## Разработка

### Добавление нового фильма

1. В админ-панели перейдите в раздел "Фильмы"
2. Нажмите "Добавить фильм"
3. Заполните форму:
   - Название
   - Описание
   - Год выпуска
   - Режиссер
   - Жанры
   - Постер

## Безопасность
